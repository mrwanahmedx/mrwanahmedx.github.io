WORKFLOW ENGINEERING / CASE E
N8N · WEBHOOKS · BILINGUAL EXTRACTION · SQLITE

From group message
to structured job.

An inspectable ten-node n8n workflow prototype for UAE film and events hiring posts. WAHA-shaped English and Arabic messages are normalized, classified, checked for required fields and routed toward an HTTP job-form API.

Input
Synthetic WhatsApp-group event objects shaped like WAHA webhooks, including message IDs, group identities and free-form text.
Flow
Webhook → normalize → parse → validate → conditional HTTP request → response. Non-jobs and private messages are ignored; incomplete jobs require review.
Backend
A separate local Python REST service persists accepted jobs into SQLite and detects duplicate external IDs. It can simulate HTTP 503 responses for retry tests.
Status
Self-directed source prototype, not a client deployment. Actual WAHA account, LLM model, client API and native n8n webhook end-to-end run are not yet connected or verified.

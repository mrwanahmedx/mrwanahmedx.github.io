DATA EXTRACTION / CASE C

Controlled catalog extraction.

This self-initiated Python demonstration extracts a controlled two-page product catalog into reviewable CSV files. It is not a paid-client engagement or evidence of permission to scrape unrelated commercial sites.

What is demonstrated

  • Extract a defined set of fields from two locally controlled HTML pages.
  • Follow pagination rather than silently stopping after the first page.
  • Normalize prices and deduplicate repeated product identifiers.
  • Write clean records and malformed input records to separate CSV outputs.

Verification

Three local automated tests passed on October 9, 2026: CSV output generation, pagination/cleaning/deduplication/error handling, and price normalization. All ten tests across the three portfolio demonstrations passed. This is an independent demonstration rather than a security audit.

Local evidence files

The complete project package contains catalog_extractor.py, run_demo.py, controlled HTML sample pages, tests/test_catalog_extractor.py, output/catalog.csv and output/errors.csv. Source files are included in the locally tested portfolio archive.

# Public Portfolio Strategy

This file defines the recruiter-facing hierarchy. It is intentionally narrower than the full GitHub account: not every historical repository deserves equal visibility.

## Featured

1. **Data Observatory** — synthetic credit-risk analytics, model validation, IFRS 9 research modules, tested browser case studies.
2. **EGX Quant Research** — point-in-time quantitative research, data QA, holdout protection and documented failed scanner lineage.
3. **Credit Risk Management Database** — grain-safe SQL, data contracts, reconciliation and CI.

## Featured research modules

- **IFRS 9 Credit Risk Modeling** — synthetic ECL, staging, scenarios, PD/LGD/EAD and regression tests.
- **Credit Risk Model Validation** — AUC/Gini, KS, Brier, calibration, PSI, observed-vs-expected testing and explicit validation verdicts.

## Supporting

- **HR Attrition Analysis** — cleaned exploratory Python notebook using a public IBM dataset.
- **Crypto Quant Scanner** — discontinued research lineage retained as evidence of testing and strategy rejection.

## Legacy / not recruiter-featured

Historical dashboard work remains available as history where appropriate, but is deliberately excluded from the active portfolio path when it is weaker, stale, or has not completed artifact-level confidentiality review.

## Selection rule

A project becomes Featured only when it quickly demonstrates at least one of:

- credit-risk/model-development capability,
- model-validation discipline,
- data-engineering correctness,
- quantitative research rigor,
- reproducible testing and governance.

A project is not promoted merely because it is visually polished or has many files.

## Confidentiality rule

No featured project may rely on employer/customer data, internal schemas, proprietary code, private model parameters, confidential screenshots, or reconstructed workplace logic.
